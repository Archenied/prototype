# 프로토타입 — 시각·날씨·교통 (Windows 버전)

시각·날씨·버스·지하철·경로·신호등을 한 화면에서 보는 앱입니다.
VibePlanner 인계 패키지(revision 211)를 바탕으로 만든 **반응형 웹 앱 + Windows 실행 파일**입니다.

## 실행하기

1. `Prototype.exe`를 더블클릭합니다.
2. 주소창 없는 앱 창이 열립니다. 창을 닫으면 뒤에서 돌던 서버도 함께 꺼집니다.

필요한 것: **Node.js**(이 PC에는 이미 있음)와 **Microsoft Edge**(Windows 기본).
`Prototype.exe`는 이 폴더 안에 그대로 두고 실행해야 합니다.

## API 키 넣기

1. `API_KEYS.bat`를 더블클릭하면 메모장으로 열립니다.
2. `set 이름=` 뒤에 키를 붙여 넣고 저장(Ctrl+S)합니다. 띄어쓰기는 넣지 마세요.
3. 저장하는 즉시 반영됩니다 (앱을 다시 켤 필요 없음).
4. 키가 없는 정보는 **데모 데이터**로 보이고, 홈 위쪽에 노란 `데모 데이터` 표시가 생깁니다.
   설정 → "API 키 상태"에서 어떤 정보가 실제 데이터인지 확인할 수 있어요.

**공공데이터포털 키 하나 + 카카오 키**만 있으면 경로 소요 시간을 뺀 모든 정보가 실제 데이터로 나옵니다.

| 키 이름 | 쓰는 곳 | 받는 곳 (무료) |
|---|---|---|
| `DATA_GO_KR_KEY` | 날씨 · 서울/경기 버스 · 지하철(시간표) · 신호등 | data.go.kr — 아래 6개 서비스에 각각 **활용신청** (키는 하나로 같음) |
| `KAKAO_REST_KEY` | 지역·장소 검색 | developers.kakao.com — 내 애플리케이션 → REST API 키 |
| `SEOUL_OPENAPI_KEY` (선택) | 지하철 **실시간** 도착·지연 | data.seoul.go.kr. 없으면 공공데이터포털 시간표로 보여 줌 |
| `ODSAY_KEY` (선택) | 경로 소요 시간 | lab.odsay.com. 공공데이터포털에는 대중교통 경로 API가 없음 |
| `TDATA_KEY` (선택) | 서울 신호등 | t-data.seoul.go.kr. 없으면 공공데이터포털 신호 API 사용 |

data.go.kr에서 활용신청할 서비스 (검색창에 이름을 넣고 → 활용신청):

1. 기상청_단기예보 ((구)_동네예보) 조회서비스 — 날씨
2. 서울특별시_정류소정보조회 서비스 — 서울 버스
3. 경기도_버스도착정보 조회 서비스 — 경기 버스 도착
4. 경기도_정류소 조회 서비스 — 경기 정류장 검색
5. 국토교통부_(TAGO)_지하철정보 — 지하철 시간표
6. 행정안전부 한국지역정보개발원_(전국 통합데이터) 교통안전 신호등 실시간 정보 — 신호등

신청하지 않은 서비스는 앱에서 "API_KEYS.bat에 넣은 키를 확인해 주세요" 안내가 뜹니다. 승인 직후 1~2시간은 키가 안 먹을 수 있어요.

`API_KEYS.bat`는 남에게 보내거나 공유하지 마세요.

## 화면 구성

- **홈**: 맨 위에 시각·날씨·교통 요약이 항상 보이고, 아래 탭(날씨 · 교통 전체 · 버스 · 지하철 · 경로 · 신호등)으로 자세히 봅니다.
  탭 내용은 스크롤 없이 한 화면에 들어오고, 많으면 `‹ 1/2 ›` 페이지로 나뉩니다.
- **F5** 또는 오른쪽 위 새로고침 버튼: 다시 불러오기 (방금 받은 정보면 호출하지 않고 그대로 둠)
- **Ctrl + ,**: 설정 열기
- **Ctrl + Shift + D**: 시험 도구 — 지연·시간 초과·서비스 오류·한도 초과·조회 불가·오프라인을 흉내 내서 화면 상태를 확인합니다.

## 저장되는 곳

| 무엇 | 어디 |
|---|---|
| 날씨 지역·교통 대상·알림·마지막 데이터 | `%LOCALAPPDATA%\Prototype-TWT\EdgeProfile` (앱 창 전용 저장소) |
| 피드백·익명 지표·서버 로그 | 이 폴더의 `data\` |

앱이 켜져 있을 때 `http://127.0.0.1:48620/admin` 을 브라우저로 열면 **운영자 화면**(피드백 유형별 목록, M-01~M-05 지표 요약)을 볼 수 있습니다.

## 다시 빌드하기

`launcher\Launcher.cs`를 고쳤다면 `BUILD.bat`를 실행하면 `Prototype.exe`가 다시 만들어집니다 (Windows 기본 C# 컴파일러 사용).
웹 화면(`web\`)과 서버(`server\`)는 고친 뒤 앱을 다시 켜기만 하면 됩니다.

## 알려진 한계

- **알림**: Windows 버전은 앱 창이 열려 있을 때(최소화 포함)만 출발 알림이 뜹니다. 닫혀 있는 동안 지난 알림은 늦게 울리지 않습니다.
- **실제 API 연결은 키가 없어서 아직 확인하지 못했습니다.** 모든 화면은 데모 데이터로 시험했습니다. 특히 신호등(T-data V2X)은 응답 형식을 확인하지 못해서, 다르면 "신호 정보 제공 안 됨"으로 보입니다.
- **지하철**: 공공데이터포털 키만 있으면 **시간표 기준**(실시간 아님, 화면에 표시됨)이고 운행 지연 정보도 없습니다. 실시간·지연은 서울 열린데이터광장 키가 필요합니다. 공휴일은 평일 시간표로 계산될 수 있어요.
- **신호등**: 공공데이터포털 실시간 신호는 2026년 현재 일부 지역(울산 등)만 제공된다는 보고가 있어서, 서울·경기 교차로는 대부분 "신호 정보 제공 안 됨"으로 보일 수 있습니다.
- **버스**: 서울·경기 정류장 모두 됩니다 (검색하면 두 곳 결과가 함께 나옴).
- **Android 앱 알림**: Android 앱에서는 출발 알림(브라우저 알림)이 아직 뜨지 않습니다.
- **iOS 앱**: 기획에 있지만 아직 만들지 않았습니다. 웹 코드는 그대로 다시 쓸 수 있습니다.

## Windows exe 하나로 설치 · Android 앱 · 시계 보정 (1.3.0)

- **Prototype.exe 하나만 받아도 돼요**: 옆에 `server` 폴더가 없으면 GitHub(main ZIP)에서 앱을 받아 `%LOCALAPPDATA%\Prototype-TWT\app`에 설치하고, 바탕화면·시작 메뉴에 "프로토타입" 바로 가기를 만든 뒤 그곳의 앱을 실행해요. 업데이트는 그 폴더에서 평소처럼 받아요. (ZIP을 풀어서 쓰는 방법도 그대로 됩니다.)
- **Android 앱** (`android/`): 화면 파일(`web/` + 공급자 코드)이 APK 안에 들어 있는 WebView 앱이에요. 앱이 서울 버스 API(http)를 대신 받아 줘서 서울 버스도 보여요. GitHub Releases에 새 APK가 있으면 왼쪽 아래 업데이트 → 설치 화면이 열려요.
  - 빌드: `.github/workflows/android.yml`이 version.json이 바뀔 때 APK를 만들고, 가상 휴대폰(에뮬레이터)에 설치해 실행해 본 뒤 Release(`v버전`)에 `Prototype.apk`·`Prototype.exe`를 올려요.
  - 서명 키: 저장소 Secrets(`PROTO_KEYSTORE_B64`, `PROTO_KEYSTORE_PASSWORD`, `PROTO_KEY_ALIAS`, `PROTO_KEY_PASSWORD`). 백업은 이 PC의 `Downloads\Claude product\prototype-signing\`에만 있어요 (GitHub에 올리지 않음). **잃어버리면 새 버전을 옛 앱 위에 설치할 수 없어요.**
- **시계 보정**: 화면 시계는 기기 시계로 매끄럽게 움직이고, 인터넷 표준 시각(NTP: time.google.com 등)과 0.3초 넘게 다르면 그 차이만큼 고쳐서 보여 줘요. 10분마다·인터넷이 다시 연결될 때·기기 시계가 갑자기 바뀔 때 다시 재요. 인터넷이 끊겨도 마지막 보정값을 계속 써요. 설정 → **시간 맞추기**에 지금 상태가 나와요. (PC: 서버가 NTP, Android: 앱이 NTP, 휴대폰 브라우저: 웹 서버 시각, 1초 단위)

## Windows 앱 창 · iPhone 홈 화면 앱 (1.4.0)

- **Windows**: Prototype.exe가 이제 Edge 창이 아니라 **자기 창**을 열어요 (안의 화면은 Windows에 들어 있는 WebView2 엔진). 그래서 작업 표시줄에 고정해도 Edge가 아니라 프로토타입이 고정돼요. 이미 열려 있으면 그 창을 앞으로 가져와요. 창 크기·위치를 기억하고, 출발 알림은 Windows 알림으로 떠요.
  - WebView2 SDK 파일(`launcher\webview2\`, Microsoft.Web.WebView2 1.0.2903.40)은 exe 안에 들어 있고, 실행할 때 `%LOCALAPPDATA%\Prototype-TWT\bin`에 꺼내요. 화면 저장소: `%LOCALAPPDATA%\Prototype-TWT\WebView2` (처음 한 번 예전 Edge 프로필의 설정을 옮겨 와요).
  - WebView2를 쓸 수 없는 PC면 예전처럼 Edge 앱 창으로 열어요. (`PROTOTYPE_USE_EDGE=1`로 강제 가능)
  - 시험: `PROTOTYPE_DATA_ROOT`(설정 폴더 바꾸기) + `PROTOTYPE_SHOT=파일.png`(화면이 뜨면 스크린샷 찍고 닫기).
- **iPhone**: Safari → 공유 → 홈 화면에 추가 → 아이콘으로 열면 주소창 없는 앱이 돼요. 아이콘(`apple-touch-icon.png`), 노치·홈 막대 여백, 인터넷 없이 열리기(`web/sw.js`)를 넣었어요. 서울 버스는 브라우저 제한 때문에 안 돼요. App Store/TestFlight 앱은 Apple 개발자 계정(연 $99)이 있어야 해요.

## 날씨 자세히 (1.5.0)

- 홈 → **날씨** 탭: 왼쪽은 기상청 실황(공식 관측) + 체감온도·기압·바람 방향, 오른쪽은 **Open-Meteo**(무료, 키·계정 필요 없음) 자세한 날씨.
  - **7일 시간별** (옆으로 넘기기, 168시간): 기온, 체감, 비·눈 올 확률 막대, 강수량·적설, 바람 화살표. 누르면 그 시간의 **모든 값**.
  - **7일 예보** (옆으로 넘기기): 최고/최저, 체감, 강수확률·양·시간, 눈, 바람·돌풍, 자외선, 미세·초미세먼지 등급, 일출·일몰. 누르면 그날로 이동.
  - **모든 값**: 기온, 체감온도, 강수확률, 강수량(비·소나기), 새로 쌓인 눈·쌓인 눈, 습도, 이슬점, 기압(해면·지표, 오르내림), 바람(방향 "북서풍 (북서 → 남동)", 보퍼트 이름), 돌풍, 구름 양(낮은·중간·높은), 안개·시정, 자외선, 햇빛 든 시간, 어는 높이, 뇌우 에너지(CAPE), 낮/밤.
  - **대기질·해와 달**: PM10, PM2.5(환경부 등급), 오존, NO₂, SO₂, CO, 황사, 대기 탁도(AOD), 일출·일몰·낮 길이, 달 모양(계산).
- 코드: `server/openmeteo.mjs` (PC 서버 `/api/weather/detail`, 휴대폰은 `direct.js`가 같은 코드를 브라우저에서 실행), 화면 `web/js/views/weather.js`. 10분마다 새로 받아요.
- 기상 모델 값이라 기상청 관측(왼쪽)과 습도·기온이 조금 다를 수 있어요.

## 내 주변 신호등 (1.5.1)

- 홈의 **신호등** 탭은 이제 항상 보여요. 저장하지 않아도 **내 위치**(허용 안 했으면 홈 날씨 지역) 가까운 신호등 최대 4곳을 자동으로 보여 주고, 저장한 신호등도 함께 보여요. 목록은 5분마다, 신호는 10초마다 새로 받아요.
- 신호등이 안 보였던 이유: 공공데이터포털 키가 신호등 서비스(한국지역정보개발원_교통안전 신호등 실시간 정보, B551982)에 **활용신청이 안 돼 있어서** 모든 요청이 "등록되지 않은 서비스키"(코드 30)로 거절됐어요. 이제 화면에 신청 방법과 data.go.kr 링크가 나와요. 승인되면 자동으로 보여요.
- 참고: 이 서비스의 실시간 신호는 2026년 기준 일부 지역만 제공된다는 보고가 있어서, 승인 뒤에도 서울·경기는 "신호 정보 제공 안 됨"일 수 있어요.

## 달력 · 오늘은 무슨 날 (1.6.0)

- 홈 → **달력** 탭: 왼쪽에 오늘(또는 고른 날)의 모든 특별한 날과 설명·음력 날짜·내 일정, 오른쪽에 **월/주** 달력. ◀▶ 한 달, ◀◀▶▶ 1년(주 보기에서는 1주/4주), **오늘** 버튼.
- 시계 카드 날짜 아래에 "오늘은 …" 한 줄.
- 특별한 날은 모두 앱 안에서 계산 (`web/js/days.js`, 인터넷·키 필요 없음, 어느 해든):
  - 공휴일 + **대체공휴일**(설·추석·어린이날은 겹침도, 3·1절·광복절·개천절·한글날·부처님오신날·성탄절은 주말) — 2024~2027 실제 달력과 맞는 것 확인
  - **음력 명절**(설날·정월대보름·삼짇날·부처님오신날·단오·유두·칠석·백중·추석·중양절·섣달그믐): 브라우저의 한국 음력(Intl dangi) 달력 사용
  - **24절기**: 태양 황경 천문 계산(분 단위), 한식(동지+105일), **삼복**(경일 계산)
  - 국경일·법정기념일, 세계의 날, ○○데이(빼빼로데이·블랙데이 등), n번째 요일 기념일(성년의 날·서해수호의 날 등)
- **내 일정**: 날짜·시간(선택)·제목·메모·반복(매주/매달/매년). 이 기기에만 저장(`state.events`).
