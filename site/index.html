Windows 설치 방법

  1. 위의 Windows용 다운로드를 눌러 ZIP을 받아요.
  2. ZIP을 마우스 오른쪽 → 압축 풀기.
  3. Node.js(LTS)가 없으면 설치해요.
  4. Prototype.exe를 더블클릭하면 앱이 열려요.
  5. 실제 정보를 보려면 API_KEYS.bat을 열어 공공데이터포털 키를 넣어요. (키가 없으면 데모 데이터)

새 버전이 나오면 앱 왼쪽 아래에 업데이트 버튼이 떠요. 누르면 GitHub에서 바로 받아서 다시 열려요.

휴대폰에서 쓰기

  1. 휴대폰에서 열기를 눌러요. (이 페이지 주소 뒤에 /app/)
  2. 설정 → API 키에 공공데이터포털 키를 넣어요. 키는 그 휴대폰에만 저장돼요.
  3. 브라우저 메뉴에서 홈 화면에 추가를 누르면 앱처럼 열려요.
