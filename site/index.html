진짜로 돌아가는 중

설치하기 전에 써 보세요

오른쪽 휴대폰 화면은 사진이 아니라 실제 앱이에요. 시계가 움직이고 날씨·버스·지하철이 새로 고쳐져요. 누르면 전체 화면으로 열려서 모든 화면을 직접 눌러 볼 수 있어요. iPhone·Android·PC 모두 돼요.

아직 저장한 게 없으면 예시(명동·광화문 정류장·시청역)와 데모 데이터로 보여 주고, 아무것도 저장하지 않아요.

Windows 설치 방법

  1. Node.js(LTS)가 없으면 먼저 설치해요.
  2. 위의 Prototype.exe 받기를 눌러 받고 더블클릭해요.
  3. 처음 한 번은 GitHub에서 앱 파일을 받아 설치해요. 바탕화면에 프로토타입 바로 가기가 생겨요.
  4. 실제 정보를 보려면 앱의 설정 → 키 파일 열기에서 공공데이터포털 키를 넣어요. (키가 없으면 데모 데이터)
  5. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요.

새 버전이 나오면 앱 왼쪽 아래에 업데이트 버튼이 떠요. 누르면 GitHub에서 바로 받아서 다시 열려요.

Android 앱 설치

  1. 휴대폰에서 Android 앱 받기를 눌러 Prototype.apk를 받아요.
  2. 받은 파일을 열고, 물어보면 이 브라우저의 출처를 알 수 없는 앱 설치를 허용해요.
  3. 설정 → API 키에 공공데이터포털 키를 넣어요. 키는 그 휴대폰에만 저장돼요.
  4. 새 버전이 나오면 앱 왼쪽 아래에 업데이트가 떠요.

iPhone 홈 화면 앱 설치

  1. iPhone의 Safari로 이 페이지를 열고 iPhone에서 열기를 눌러요.
  2. 아래쪽(또는 위쪽) 공유 버튼(네모에 화살표) → 홈 화면에 추가.
  3. 웹 앱으로 열기가 켜져 있는지 보고 추가를 눌러요.
  4. 홈 화면의 프로토타입 아이콘으로 열어요. 설정 → API 키에 공공데이터포털 키를 넣어요.

휴대폰 브라우저에서 쓰기 (설치 없이)

  1. 휴대폰에서 열기를 눌러요. (이 페이지 주소 뒤에 /app/)
  2. 설정 → API 키에 공공데이터포털 키를 넣어요. 키는 그 휴대폰에만 저장돼요.
  3. 브라우저 메뉴에서 홈 화면에 추가를 누르면 앱처럼 열려요.
